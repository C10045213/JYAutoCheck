### JYAutoCheck
项目基于 python playwright 与**特殊页面**与**特殊、固定元素**实现并集成一系列脆弱的浏览器自动化，其中涉及调用AI执行关键自动化过程。

此浏览器自动化通过9222端口监听已打开浏览器来运行，且无法“无人值守”运行。

#### 一般流程（以单发审题为例）
1. 菜单General -> 浏览器9222启动/重启动
2. 菜单AI Config -> 选择模型：选择供应商与模型
3. 菜单AI Config -> 模型参数：（非必需）调节reasoning_effort（思考强度）与max_completion_tokens（token限制）
4. 在打开的浏览器中，打开特殊页面。审题为两个页面：审题窗口、加工\试题查询
5. 菜单Mono -> 单发审题 Mono#1
3.1. 菜单General -> 编辑提示词： （非必需）编辑相应提示词
6. 点击按钮“启动”，则开始对当前页试题进行自动审核
7. 审核结束后，返回结果将呈现于GUI的下方

#### 特殊页面说明
- 单发/并发审题：两个页面
  - 答题\开始审题\开始审核（审核窗口）
  - 加工\试题查询

- 单发/并发复审：一个页面
  - 答题\答题统计
  - **或者**、答题\审题统计
 
- 单发/并发加工：一个页面
  - 加工\加工试题
 
#### 复审额外说明
- 按钮“表单”：选中后，点击按钮“填入”将对选中项进行修改。
  - 其中“题目”勾选与否没有作用。
  - 其中“考点+”勾选后才会修改考点。
- 按钮“填入”：将返回的各项数据分别填入。
- 按钮“保存”：保存填入的项目。
  - 长按：以选择保存方式：仅保存、保存并下一页、保存并上一页、保存并刷新。
  - 短按：执行选择的保存方式
- 选择框“AUTO”：选中后自动执行各项填入

---
##### 按钮“终止”说明
将尝试终止当前的任务。
对于单发，将会在API有响应后才终止。
对于并发，将会终止接下来的信息采集与未发生的API调用，对于已发生的API调用，将会在API有响应后才终止，并丢弃所有返回结果。

##### 菜单AI Config -> 进入调试模式
在菜单General -> 编辑提示词 -> 调试 提示词/调试 测试输入，分别对应输入系统提示词、用户输入提示词。
点击按钮“启动”，将呈现API的完整返回内容。

##### 菜单AI Config -> stage config -> Task2参数设置
为“并发复审（旧）”的特殊选项，将对四个环节分别设置供应商、模型、思考强度以及token限制

##### 菜单General -> 重置playwright连接
当页面未能锁定、锁定错误（非目标特殊页面）、意外关闭时，关闭多余页面，打开特殊页面，并点击此菜单项，可以重新定位并锁定页面。
